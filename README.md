# STARWAKE

탑다운 우주 슈터. 적 웨이브를 격파하고 멀티샷·실드·부스트를 모아 최고 점수에 도전하세요.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 화살표 | 이동 |
| 마우스 | 조준 |
| 클릭 / 스페이스 / Z | 사격 |
| Esc / P | 일시정지 |
| 터치 | 화면을 밀어 이동, 누르는 동안 자동 사격 |
| 게임패드 | 스틱 이동, A / RT 사격 |

## 플레이

- 목숨 3. 정찰기 · 요격기 · 돌격함이 웨이브마다 강해집니다.
- 멀티샷, 실드, 부스트, 추가 목숨을 주우세요.
- 최고 점수는 이 기기에 저장됩니다.

## 실행

```bash
npm install
npm run dev
```
